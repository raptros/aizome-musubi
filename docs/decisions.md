| A7 | 2026-11-22 | Pulse-visible values follow `aizome-sys`'s expectation model, as Settei does: a write shows at once and is held for at most 1 s (`EXPECT_FOR`) until the server reports, after which the server's value wins. A refused write is therefore visible for ≤1 s. Musubi must (a) surface the command's `Done` error in the status bar, (b) enter mixer undo history only after `Done` is Ok, and (c) never keep its own copy of a dragged value after release. Native-Props controls keep strict read-back (A1).
